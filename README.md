# 555 Timer Based LED Flasher – PCB Design

## Project Overview
Designed a 555 Timer-based LED Flasher circuit using EasyEDA Pro. The circuit operates in astable mode to generate continuous LED blinking.

## Project Specifications
- **Timer IC:** NE555
- **Operating Voltage:** 5V DC
- **Operating Mode:** Astable Multivibrator
- **Blinking Frequency:** Approximately 1 Hz
- **Design Software:** EasyEDA Pro

## Components Used
- NE555 Timer IC
- Resistors: 1kΩ, 68kΩ, 330Ω
- Capacitors: 10µF, 100nF, 10nF
- Red LED
- 5V DC input connector

## Design Process
1. Circuit schematic design
2. Component selection and footprint assignment
3. PCB component placement
4. Copper track routing
5. Design Rule Check (DRC)

## Design Verification
Successfully completed PCB Design Rule Check (DRC) with no issues found.

## Project Files
- `Gerber/` – PCB fabrication ZIP
- `Schematic/` – Circuit schematic
- `PCB_Design/` – PCB layout and 3D view

## Tools Used
EasyEDA Pro

## Learning Outcomes
Gained practical experience in electronic circuit design, PCB layout, component footprints, copper routing and design verification.

**Note:** This project is a PCB design; the board has not yet been physically fabricated or tested.
